# 弟弟记账本

一个给家人用的极简记账网页（单文件、纯前端、零后端）。

- 数据只存在**使用者的手机/电脑浏览器**里（localStorage），不上传任何服务器。
- 支持「记一笔 / 明细 / 统计 / 设置」四个页面，可设月度预算与存钱目标。
-  iPhone 用 Safari 打开后，点「分享 → 添加到主屏幕」，就能当 App 使用，断网也能记账。

## 文件说明

- `index.html` —— 主页入口。GitHub Pages 开启后访问 `https://<用户名>.github.io/<仓库名>/` 即打开。
- `弟弟记账本.html` —— 同内容的中文名副本，方便直接发给家人用（微信/隔空投送均可）。

两个文件内容完全一致，二选一使用即可。

## 本地预览

直接用浏览器打开 `index.html` 或 `弟弟记账本.html` 即可，无需任何服务器。

## 部署（GitHub Pages）

1. 在本仓库开启 Pages：仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支选 `main` → 目录选 `/ (root)` → Save。
2. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

## 数据备份与迁移

在「设置」页点「导出备份」可下载 JSON；换手机/清缓存前记得导一份，再到新设备的「设置」点「导入备份」恢复。
